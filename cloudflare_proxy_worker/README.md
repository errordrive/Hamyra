# StreamBD Proxy Cloudflare Worker (`streambd-proxy`)

This is the deployable Cloudflare Worker for **`streambd-proxy.aininjaibrahim.workers.dev`**. It acts as the high-performance media & HLS proxy for the Hamyra Android app.

---

## Capabilities

1. **`/?get_cookie=1`**: Returns session cookies and referers for Toffee live streams.
2. **`/hls?t=<token>`**: Decrypts AES-256-GCM tokens generated by the Android app (`vf4.java`), forwards requests with appropriate `Referer` and `User-Agent`, and rewrites HLS (`.m3u8`) playlists so relative `.ts` segments are streamed through the proxy.
3. **Range Header & Seeking**: Transparently supports `Range: bytes=...` for instant video seek and buffering on ExoPlayer / Media3.
4. **`/encrypt?url=...&ref=...`**: Helper endpoint to generate encrypted tokens for testing or adding new channels to `channels.json`.

---

## Quick Start & Deployment

### 1. Install Dependencies
```bash
cd /storage/emulated/0/ApkLab/MovieApp/cloudflare_proxy_worker
npm install
```

### 2. Login to Cloudflare
```bash
npx wrangler login
```

### 3. Test Locally
```bash
npm run dev
# or: npx wrangler dev
```

Test the cookie endpoint:
```bash
curl http://localhost:8787/?get_cookie=1
```

### 4. Deploy to Cloudflare
```bash
npm run deploy
# or: npx wrangler deploy
```

Once published, your worker will be available at:
`https://streambd-proxy.<your-subdomain>.workers.dev`
